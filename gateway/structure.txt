Module grouping:

- `main.rs`: async runtime and logging initialization; calls `app::run()`.
- `app.rs`: component construction, startup wiring and cleanup.
- `telemetry.rs`: async telemetry event client for Supervisor-owned event aggregation.
- `capabilities/`: contracts for replaceable functionality.
- `clients/`: outbound clients for adjacent services owned by other processes.
- `core/`: orchestration state, event types, context assembly, history, persona,
  output, and timing primitives used by the gateway runtime.
- `core/pipeline/run.rs`: event loop with a separate P0 branch, using borrowed
  application components and owned receivers/turn/narration state.
- `lifecycle/`: Gateway-local async tasks, connections, reconnect and shutdown.
- `sandbox/`: client for Supervisor-owned sandbox resources.
- `services/`: inbound server surfaces exposed by the gateway.
- `rag/`: retrieval, ranking, embedding, and persistence.

`lib.rs` re-exports the nested modules at their previous public paths, so code
can continue to use paths like `crate::types` and `kaguya_gateway::talker`
while the physical source tree stays organized by responsibility.
